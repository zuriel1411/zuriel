ETIQUETAS SEMÁNTICAS


REGRESAR

header

Se utiliza para colocar el encabezado de una página o sección.

nav

Se utiliza para crear una sección de navegación con enlaces.

main

section

Sirve para dividir el contenido en diferentes secciones.

article

Se utiliza para colocar contenido independiente, como una noticia o publicación.

aside

Contiene información complementaria al contenido principal.

search

Representa una zona de búsqueda dentro de una página web.

address

Se utiliza para mostrar información de contacto.

footer

Representa el pie de página de un sitio web.
