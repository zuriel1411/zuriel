    Lista de definiciones

    HTML
    Lenguaje utilizado para crear páginas web.
    CSS
    Lenguaje utilizado para dar diseño a las páginas web.
    Internet
    Red mundial que conecta diferentes dispositivos.
    Navegador
    Programa utilizado para acceder a páginas web.
    Servidor
    Computadora que proporciona servicios o información.
    URL
    Dirección de un recurso disponible en Internet.
    Frontend
    Parte de una página web que puede ver el usuario.
    Backend
    Parte de una página web que funciona detrás de la interfaz.
    JavaScript
    Lenguaje que permite agregar interacción a una página web.
    Web
    Sistema de páginas y recursos que funciona mediante Internet.
