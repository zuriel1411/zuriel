REGRESAR

HTML nació en 1989 gracias a Tim Berners-Lee para compartir información en Internet. En 1991 apareció la primera versión de HTML, con etiquetas sencillas para textos y enlaces. Durante los años 90 surgieron nuevas versiones que permitieron crear páginas más completas. En 2014 se publicó HTML5, incorporando mejoras para multimedia y aplicaciones web. Actualmente, HTML es fundamental para crear y estructurar páginas web junto con CSS y JavaScript.
