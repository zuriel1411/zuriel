20 Etiquetas HTML poco usadas

1. <abbr>

Descripción: Define una abreviatura o acrónimo.

Ejemplo: HTML

2. <bdi>

Descripción: Aísla texto para evitar problemas con la dirección de escritura.

Ejemplo: Usuario: Texto árabe

3. <bdo>

Descripción: Permite cambiar la dirección del texto.

Ejemplo: Hola mundo

4. <cite>

Descripción: Indica el título de una obra.

Ejemplo: El Principito

5. <data>

Descripción: Relaciona un texto visible con un valor que puede interpretar una computadora.

Ejemplo: Producto

6. <del>

Descripción: Representa texto que ha sido eliminado.

Ejemplo: Precio anterior: $500

7. <ins>

Descripción: Representa texto que ha sido agregado.

Ejemplo: Precio nuevo: $400

8. <kbd>

Descripción: Representa una tecla o entrada realizada con el teclado.

Ejemplo: Presiona Ctrl + C

9. <mark>

Descripción: Resalta una parte importante del texto.

Ejemplo: Este texto tiene una palabra resaltada.

10. <meter>

Descripción: Representa una medida dentro de un rango conocido.

Ejemplo: Batería: 70%

11. <output>

Descripción: Muestra el resultado de un cálculo o acción.

Ejemplo: Resultado: 25

12. <progress>

Descripción: Muestra el progreso de una tarea.

Ejemplo: Descarga: 70%

13. <q>

Descripción: Representa una cita corta.

Ejemplo: El conocimiento es poder.

14. <ruby>

Descripción: Permite colocar una anotación sobre caracteres, especialmente para pronunciación.

Ejemplo: 漢kan

15. <s>

Descripción: Representa información que ya no es válida o relevante.

Ejemplo: $999 $699

16. <samp>

Descripción: Representa la salida de un programa o sistema.

Ejemplo: Error 404: Página no encontrada

17. <time>

Descripción: Representa una fecha u hora.

Ejemplo: 23 de septiembre de 2026

18. <wbr>

Descripción: Indica un lugar donde el navegador puede realizar un salto de línea.

Ejemplo: Supercalifragilistico

19. <details>

Descripción: Crea una sección que se puede abrir y cerrar.

Ejemplo:

Haz clic para ver más

Este contenido estaba oculto.

20. <dialog>

Descripción: Representa una ventana de diálogo.

Ejemplo:

Hola, esta es una ventana de diálogo.
